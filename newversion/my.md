# 叙事段落：通用 prompt 的局限与 image-specific 补齐

## 当前版本

现有 zsad 方法通常采用通用的异常 prompt。这类文本表述具有良好的跨类别泛化能力，但仅在类别无关的宽泛语义层面刻画“异常”，缺乏对当前图像中异常实际形态的描述。由此导致异常侧语义过宽：显著偏离正常模板的正常结构（如规则纹理、花纹）也被划入异常一侧，产生误响应。收紧异常侧语义，需要当前图像中异常的位置与形态信息，而该信息无法由通用 prompt 预先确定，须在测试阶段逐图像地从图像自身获取。为此，我们利用图像高频分量所刻画的局部结构偏离，作为无监督条件下的可计算依据，将异常侧语义对齐到当前图像的实际异常上。

## 迭代记录

### v1 — 初始表述
我们发现使用通用的 prompt，可能会导致误将花纹等当成异常，这是因为用于 zsad 的通用的异常表述具有很好的泛化性却缺少了具体图像中的实际异常描述。通过实验发现，当在通用 prompt 外添加具体的异常描述可以有效提高检测的精度。

### v2 — 补上后半段（局部结构偏离）
我们发现使用通用的 prompt，可能会导致误将花纹等当成异常，这是因为用于 zsad 的通用异常表述泛化性很好，却缺少具体图像中的实际异常描述；实验也表明，在通用 prompt 外补上具体的异常描述能有效提高检测精度。由于每张图像的异常各不相同，这一描述在测试时针对每张图像单独补齐，其依据来自图像自身所暴露出的局部结构偏离。

### v3 — 显式点出高频分量
我们发现使用通用的 prompt，可能会导致误将花纹等当成异常，这是因为用于 zsad 的通用异常表述泛化性很好，却缺少具体图像中的实际异常描述；实验也表明，在通用 prompt 外补上具体的异常描述能有效提高检测精度。由于每张图像的异常各不相同，这一描述在测试时针对每张图像单独补齐，其依据来自图像自身在高频分量上所暴露出的局部结构偏离。

### v4 — 口语化、去打榜
我们发现，用于 zsad 的通用 prompt 泛化性很好，但它对“异常”的描述太宽泛，容易把花纹这类正常结构也当成异常。如果针对当前这张图补上一句具体的异常描述，模型的响应就会收敛到真正的异常处。而每张图的异常各不相同，这句描述只能在测试时逐图去补，补的依据就来自图像本身高频部分暴露出的局部结构偏离。

### v5 — 学术化改写
现有 zsad 方法依赖通用的异常 prompt，这类文本表述具备良好的跨类别泛化能力，但对“异常”的刻画停留在类别无关的宽泛语义上，缺乏对当前图像中实际异常的具体刻画，导致模型倾向于将显著偏离正常模板的正常结构（如规则纹理、花纹）误响应为异常。我们观察到，若在通用 prompt 之外引入面向当前图像的具体异常描述，异常侧的语义得以收紧，模型响应随之向真实异常区域集中。鉴于异常形态随图像而异，此类具体描述需在测试阶段逐样本地在线获取；我们进一步发现，图像高频分量所刻画的局部结构偏离，可作为该描述在无监督条件下的可计算依据。

### v6 — 强化因果衔接
现有 zsad 方法依赖通用的异常 prompt。这类文本表述跨类别泛化性好，却只能在类别无关的宽泛语义上刻画“异常”，无法描述当前图像中异常的实际形态；异常侧语义过宽，使得显著偏离正常模板的正常结构（如规则纹理、花纹）也被拉向异常一侧，形成误响应。要收紧这一侧，需要的正是当前图像所缺失的那部分信息——它的异常究竟出现在何处、呈何形态。由于异常形态随图像而异，这部分信息无法由通用 prompt 预先写定，而要在测试阶段逐图像地从图像自身恢复；图像高频分量所刻画的局部结构偏离，恰好在无监督条件下提供了这一可计算的依据，使异常侧语义得以对齐到当前图像的真实异常之上。

### v7 — 整合 v5 与 v6
现有 zsad 方法依赖通用的异常 prompt。这类文本表述具备良好的跨类别泛化能力，却只能在类别无关的宽泛语义上刻画“异常”，无法描述当前图像中异常的实际形态；异常侧语义过宽，使得显著偏离正常模板的正常结构（如规则纹理、花纹）也被划入异常一侧，产生误响应。我们观察到，若在通用 prompt 之外引入面向当前图像的具体异常描述，异常侧的语义得以收紧，模型响应随之向真实异常区域集中。而收紧这一侧所需要的位置与形态信息，无法由通用 prompt 预先写定，须在测试阶段逐图像地从图像自身获取；图像高频分量所刻画的局部结构偏离，恰好在无监督条件下提供了这一可计算的依据，使异常侧语义得以对齐到当前图像的实际异常之上。
