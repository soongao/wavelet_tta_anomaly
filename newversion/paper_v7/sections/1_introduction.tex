零样本异常检测（zero-shot anomaly detection, ZSAD）要求模型在没有目标类别任何训练样本的情况下，判断图像中是否存在缺陷并定位其位置。近年来，基于 CLIP~\cite{radford2021clip} 的方法成为该任务的主流范式：通过设计或学习一组与具体物体无关的通用异常 prompt（如“正常物体”与“带缺陷的物体”），将 patch 特征与文本原型比较，即可得到逐像素的异常分数~\cite{jeong2023winclip,zhou2024anomalyclip}。其中 AnomalyCLIP~\cite{zhou2024anomalyclip} 通过学习物体无关的 prompt，显著提升了跨类别的泛化能力，成为该方向的代表性基线。

这类通用 prompt 的优势在于泛化：一套文本表述可以迁移到从未见过的物体类别上，无需为每个类别单独准备样本。然而，这种泛化是以牺牲对具体异常的刻画为代价的。通用 prompt 对“异常”的描述停留在类别无关的宽泛语义层面，它并不知道当前这张图像中的异常究竟出现在何处、呈现何种形态。其后果是异常侧的语义过宽：任何显著偏离“正常物体”模板的结构，都可能被拉向异常一侧。规则纹理、编织花纹、材质本身的粗糙度等正常结构，恰恰在特征上强烈偏离光滑的正常模板，因而容易被通用 prompt 误响应为异常（\figref{fig:motivation}）。

一个自然的设想是：如果能在通用 prompt 之外，补上一句面向当前图像的具体异常描述，异常侧的语义就会被收紧，模型的响应也会向真实异常区域集中。我们在预备实验中验证了这一设想——当为每张图像提供其实际异常的具体描述后，像素级定位质量明显改善。这说明问题不在于通用 prompt “不认识”缺陷，而在于它缺少与当前图像绑定的、足够具体的异常刻画来约束异常侧的响应范围。

但这一具体描述在 ZSAD 中无法预先获得：异常形态因图像而异，通用 prompt 在离线阶段无法一次性写定所有可能的异常外观。因此，收紧异常侧所需要的位置与形态信息，只能在测试阶段逐图像地从图像自身获取。这就引出了本文的核心问题：\emph{在无标签、逐样本的测试条件下，从图像的哪一部分可以稳定地读出“这张图的异常在哪、像什么”，从而替代那条无法预先获得的具体异常描述？}

我们注意到，异常在图像中通常表现为局部的结构性偏离——边缘的断裂、纹理的突变、孔洞的轮廓。这类偏离在频域的高频分量中被集中且可直接计算地表达出来，既不依赖标注，也不依赖对该类物体的先验知识。据此，本文提出一种高频驱动的逐图 prompt 自适应方法：在冻结的 CLIP patch 特征上读取高频分量，将其作为无监督条件下的可计算依据，在测试时逐图收紧过宽的异常侧文本表示，使其对齐到当前图像的实际异常之上。需要强调的是，高频分量同时包含异常与正常材质纹理，二者在幅度上并不可区分（\obsref{obs:ambiguity}）；因此我们并非直接把高频当作异常图，而是用它来\emph{挑选}可信证据、约束异常侧语义。整个过程冻结 CLIP、无训练、无反向传播，标签仅用于评测。

本文的贡献概括如下：
\begin{itemize}[leftmargin=1.2em,itemsep=1pt,topsep=2pt]
\item 我们指出 ZSAD 中通用异常 prompt 的一个结构性局限：其类别无关的宽泛语义使异常侧过宽，导致显著偏离正常模板的正常结构被误响应为异常；并通过引入面向当前图像的具体异常描述验证了收紧异常侧的有效性。
\item 我们将“逐图收紧异常侧”建模为一个测试时、无标签、逐样本的自适应问题，并提出以 CLIP patch 特征的高频分量作为该自适应的可计算依据，无需训练即可对齐当前图像的实际异常。
\item 在五个基准上的实验表明，本方法在像素级定位指标上较通用 prompt 基线取得一致提升，且不在正常图像上引入额外误报，同时给出机制层面的消融以厘清增益来源。
\end{itemize}
