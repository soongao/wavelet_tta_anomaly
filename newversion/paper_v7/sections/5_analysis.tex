\section{分析}
\label{sec:analysis}

本节厘清增益的来源：收紧异常侧的信息必须\emph{逐图}从图像自身读取，且高频作为无标签依据不可被简单替代。

\subsection{收紧信号从何而来（核心机制）}
\figref{fig:mechanism_ordering} 与 \tabref{tab:ablation-core} 比较五种获取“正常参照 / 收紧信号”的方式：直接把原始高频当异常图（DirectHF）、通用 prompt（不收紧）、全局固定参照（GlobalRef）、仅用 CLIP 语义置信挑参照（SelfRef）、以及本方法（逐图 + 高频依据）。

两点结论。其一，\textbf{高频不能直接当异常}：DirectHF 的像素 AUROC 从 91.1 崩到 80.0，印证 \obsref{obs:ambiguity}——高频里的正常材质纹理会淹没异常。其二，\textbf{收紧必须逐图}：全局固定参照（GlobalRef）明显差于逐图（SelfRef/Ours），因为不同材质的正常高频量级不同，任何单一阈值都两头不讨好；三档呈单调 GlobalRef $<$ SelfRef $<$ Ours。Ours 相对 SelfRef 的额外增益来自用高频依据 $\W$（而非仅 CLIP 语义）挑选正常证据，避免自证闭环。

\subsection{增益集中于纹理类}
\figref{fig:percategory_gain} 按类别比较 Ours 与 SelfRef 的像素 AUPRO。增益集中在纹理与微缺陷类（carpet、grid、tile、wood、leather、screw），而在结构化物体类（bottle、cable、transistor、metal\_nut）上基本持平。这与机制一致：纹理类正是通用 prompt 异常侧过宽、最易把花纹误响应为异常的场景，逐图收紧在此处收益最大；物体类的正常结构与异常语义本就可分，收紧不带来额外增益也不退化。

\subsection{CLIP 盲区召回}
为排除“总均值被摊薄”的干扰，我们定义 CLIP 盲区：SelfRef 判为正常但真值为异常的像素集合。\figref{fig:blindspot} 显示本方法在该盲区上召回约 $18\text{--}22\%$ 的漏检异常，而 SelfRef 依定义为 $0\%$。这直接说明高频是 CLIP 语义之外的独立信息，能捞回 CLIP 看不见的异常。

\subsection{超参敏感性}
\figref{fig:sensitivity} 考察证据比例 top-$k$、小波混合强度与正常侧更新强度 $\beta_0$。方法对 top-$k$ 稳健；小波混合曲线本身即一条机制曲线——混入过多原始高频（趋近 DirectHF）会使性能滑向崩溃，验证“读取而非融合”的必要；更新强度以小幅为佳，过大反而过拟合噪声。

\subsection{正常图稳定性与开销}
\tabref{tab:stability} 表明逐图收紧没有在正常图像上增加假阳性：Ours 的 FP 面积不高于基线。逐图收紧的额外开销约为 $+22\%$（cached 推理路径口径），因无需反向传播而可忽略。
