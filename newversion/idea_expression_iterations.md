# Idea 表达迭代记录

目标：围绕“训练好的通用 abnormal prompt、每图 detailed prompt oracle、测试时图像信息、频域证据”形成一个严谨、直击核心、通俗易懂的论文主张。

约束：

- 不使用“不是……而是……”结构。
- 不使用防御性表述。
- 不凭空造术语。
- 不把问题写成单纯提高指标。
- 不把问题写成简单模块组合。
- 不贬低训练好的通用 prompt。
- 表达要从现象出发，逐步形成机制。

作者：通用 abnormal prompt 能覆盖多种异常，detailed prompt 能让响应更具体。

审稿人：这个表达像“prompt 更详细所以更好”，缺少机制。
