同一 abnormal 概念下包含多种视觉外观不同的缺陷。训练好的通用 abnormal prompt 为了覆盖这些差异，学习到的是共享异常表达；这种共享异常表达带来泛化能力，同时也可能在某些具体缺陷外观上产生不完整响应。具体缺陷描述的作用，是弥补通用 prompt 对当前异常外观响应不完整的问题。通过 oracle detailed prompt 可以观察到，当具体缺陷描述被加入通用 prompt feature 后，部分样本中原本响应不足的异常区域会被进一步激活。

简短版本：

通用 abnormal prompt 需要覆盖多种异常外观，因此更强调共享异常表达；它的弱点是在某些具体异常外观上响应不完整。Oracle detailed prompt 显式给出当前缺陷描述，可以弥补这种响应不完整，使原本未充分激活的异常区域获得更强响应。
