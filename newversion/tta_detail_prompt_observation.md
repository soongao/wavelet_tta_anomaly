# TTA 与 Detailed Prompt Oracle 的现象观察

训练好的通用 abnormal prompt 体现了模型在训练阶段获得的跨类别异常先验，能够在不同物体和缺陷场景中提供稳定的初始判断。测试阶段的每张图仍然包含新的具体信息：当前缺陷的外观、尺度、位置、纹理背景和局部结构关系都会影响模型应当如何产生 patch response。

Detailed prompt oracle 给出了一个直接证据：当每张图的具体缺陷描述被加入到训练好的通用 prompt feature 上，模型的 patch response 会随之改变，并且在部分样本中更贴近标注异常区域。这说明测试图像中的具体异常信息能够进一步调节通用 prompt 的响应。

从 TTA 的角度看，这个现象说明，测试样本本身携带可用于适配的信息。通用 prompt 提供可迁移的异常先验，测试图像提供当前样本的具体异常线索。TTA 的研究价值就在于利用这些测试时信息，让已经训练好的模型在当前输入上形成更合适的判断。

因此，detailed prompt oracle 可以作为一个诊断实验：它展示了如果测试时能够获得当前图像的具体异常信息，训练好的 prompt feature 仍然可以被进一步调节。真实测试中需要从图像自身提取这类信息，用于完成类似的测试时适配。
