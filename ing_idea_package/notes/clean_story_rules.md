# Clean Story Rules

## 最外层故事

论文的标题、摘要、引言、贡献点、方法总览和图注，都应围绕“图内正常性锚定”展开。

正确主线：

```text
外部原型不能单独定义局部正常性 -> 当前图像内部存在正常见证 -> 发现 normal witnesses -> 锚定图内正常性 -> 判断局部证据能否被图内正常性解释
```

## 模块角色

- CLIP 文本原型：外部语义先验。
- 小波或 Haar 响应：多尺度结构一致性信号。
- Normal witnesses：当前图像中能为正常性提供证据的局部区域。
- 图内正常性锚点：由 normal witnesses 构建的局部正常性依据。
- Grounded anomaly scoring：把不能被图内正常性解释的局部结构转化为异常证据。

## 禁止叙事

- 不把方法命名为两个技术模块的组合。
- 不把单图参照估计写成论文最深贡献。
- 不把小波或频率写成本文的新颖性来源。
- 不说所有异常都表现为某个频段变化。
- 不把当前图像统计写成会更新模型的流程。
- 不把视觉正常性锚定写成图像条件 prompt。
- 不声称完全脱离语言分支。

## 写作检查

每个 paper-facing 段落都要能回答：

1. 这一段是否仍在讲图内正常性锚定？
2. 这一段是否说明了为什么外部原型不能单独定义局部正常性？
3. 小波/结构响应是否只是服务于 normal witness discovery？
4. 是否避免了把单图统计写成参数或 prompt 更新？
5. 是否没有使用目标数据集标签、掩码、正常参考图或类别统计？
