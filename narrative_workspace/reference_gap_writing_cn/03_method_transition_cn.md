# 方法过渡段：从 Reference Gap 到 Patch 证据选择

## 方法段落草稿

给定冻结 CLIP 提取的 patch 特征场，本文首先用正常/异常文本原型得到每个 patch 的语义响应。该响应提供跨图共享的异常方向，但不能单独决定当前图像中的正常外观范围。为估计图像条件化正常参照，方法需要从测试图内部选择一组可靠 patch：这些 patch 应当代表当前图像的主要材质、纹理和结构状态，同时避免被真实缺陷污染。

本文将这一选择问题建模为语义响应与局部结构变化的联合判读。具体而言，在 CLIP patch 特征网格上计算频域响应，用高频分量刻画邻域内的纹理突变、边界扰动和细粒度形变。语义响应较低且局部结构变化稳定的 patch 被聚合为当前图像的正常参照；语义响应较高且局部结构变化显著的 patch 被排除在正常参照之外，并在后续重估中以相对于该参照的偏离进行解释。这样，异常图的生成同时使用跨图语义轴和测试图自身的正常外观基准。

## 可放入 Method 3.1 的问题定义

设测试图像的 CLIP patch 特征为 \(F \in \mathbb{R}^{H \times W \times C}\)，正常/异常文本原型分别为 \(t_n\) 与 \(t_a\)。传统 CLIP-ZSAD 可由 patch 与 \(t_n, t_a\) 的相似度得到语义响应 \(S\)。本文为当前图像构造一个由 patch 证据支持的正常参照 \(r_n(I)\)。该参照随测试图像 \(I\) 改变，用于描述当前图像内部的正常外观分布。

## 可放入 Method 3.2 的频域说明

为了选择 \(r_n(I)\) 的证据，本文在 patch 特征网格上计算局部频域响应。高频分量反映相邻 patch 之间的细粒度变化，包括纹理突变、边界扰动和局部形变。与语义响应相比，该量直接刻画局部结构是否稳定，因此适合作为参照证据选择的约束。稳定区域更适合估计正常参照，突变区域需要在参照建立后再被解释为正常结构或潜在异常。

## 可放入 Method 3.3 的证据选择

证据选择使用两个条件。第一，patch 的语义响应应低于当前图像中的可疑区域，使其更可能属于正常外观。第二，patch 的局部结构变化应处在稳定范围内，使其不会把缺陷边缘或局部破损聚合进正常参照。满足这两个条件的 patch 形成正常证据集合，并通过加权聚合得到 \(r_n(I)\)。随后，每个 patch 的异常程度由其相对于 \(r_n(I)\) 的偏离和正常/异常语义轴共同决定。

## 写作注意

- 不把频域写成开头动机；先写 reference gap，再写证据选择，再引出局部结构变化和频域响应。
- 不写“频域只是辅助线索”这类退让句。正文中直接说明频域响应承担的机制角色：刻画局部结构变化，约束正常参照的证据来源。
- 不写“初始分数”。使用“语义响应”“局部异常响应”或“patch-level semantic response”。
- 不把方法写成模块堆叠。每一步都围绕“如何从当前图像内部估计正常参照”展开。
