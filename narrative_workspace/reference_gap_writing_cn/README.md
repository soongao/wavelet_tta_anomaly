# Reference Gap 中文写作工作区

本目录用于单独推进 CLIP-ZSAD 论文的中文故事线和引言写作，不直接修改 `paper/` 下的正式 LaTeX 文件。

## 文件说明

- `01_storyline_cn.md`：当前版本的故事线骨架，整合 prompt 现象、可学习文本原型、image-conditioned normal reference 与频域证据选择。
- `02_introduction_draft_cn.md`：可继续打磨的中文引言草稿，采用论文语气，不写成解释说明。
- `03_method_transition_cn.md`：从引言过渡到方法的机制段落，重点说明频域响应如何进入 patch 证据选择。
- `04_claim_evidence_map.md`：主张与证据的对应关系，区分可直接写入正文的结论、诊断现象和仍需补强的证据。

## 当前写作约束

- 主 claim 收窄为：CLIP-ZSAD 存在 reference gap，即正常/异常语义原型提供跨图共享的语义参照，但缺少当前测试图像的正常外观参照。
- 不把现有 prompt 写成“固定句子”的缺陷。文本原型可以经过学习；问题在于训练得到的是稳定语义轴，而不是当前图像的材质、纹理和结构基准。
- prompt 中加入当前图像材质、表面纹理或结构描述后定位改善，应写成 reference gap 的可观察症状：外观上下文会改变局部响应的解释。
- 频域响应服务于 patch 证据选择：它刻画局部结构变化，帮助估计当前图像的正常参照。
- 避免“重新表述整个问题”“更强频域异常分数”“初始分数”“直接融合作为异常图”等表述。
- 避免防御性写法；正文中优先写机制关系，而不是反复声明本文不做什么。
