# 中文引言草稿

CLIP 为零样本异常定位提供了直接的语义接口：视觉 patch 可以与正常/异常文本原型进行匹配，从而在没有目标类别训练样本的情况下得到异常响应。现有 CLIP-ZSAD 方法沿着这一接口不断改进文本原型、窗口匹配和视觉特征，使正常/异常语义轴更适合跨类别迁移。然而，工业缺陷通常发生在局部外观层面。划痕、污染、压痕和破损往往表现为纹理、边界或细粒度结构的局部变化，而相似的局部变化也可能来自正常材质、重复纹理或物体轮廓。局部响应是否构成异常，因此不只取决于它与异常语义原型的相似度，还取决于它相对于当前图像正常外观的偏离程度。

这一点揭示了 CLIP-ZSAD 中一个具体的 reference gap。正常/异常文本原型可以通过学习得到更稳定的语义方向，但其作用仍主要是定义跨图共享的判别坐标。对于一张具体测试图像，材质粗糙程度、表面纹理密度、结构边界位置和重复图案共同决定了“正常外观”的局部范围。缺少这一图像条件化参照时，语义响应容易把正常纹理、结构边界和真实缺陷放在相近的位置上；同一类局部响应在光滑金属上可能指向缺陷，在编织物或粗糙表面上却可能属于正常外观。

文本侧的一个现象进一步指向这一缺口。当 prompt 中显式包含当前图像的材质、表面纹理或结构信息时，部分样例的定位图会发生改善：正常纹理和结构边界上的误响应减弱，缺陷区域的响应更集中。外观描述改变的是局部响应的解释上下文，它在一定程度上补入了当前图像的正常外观信息。换言之，异常定位除了需要“正常/异常”的语义方向，还需要知道当前图像中哪些外观变化属于正常范围。

本文据此从图像侧构建 image-conditioned normal reference。给定单张测试图像，方法在冻结 CLIP 的 patch 特征场中选择可靠证据，估计当前图像的正常外观参照。该参照使每个 patch 的异常响应可以相对于当前图像内部的正常基准被解释，并与跨图共享的文本语义轴共同完成局部判读。

参照估计的核心在于 patch 证据选择。当选择过程完全由语义响应驱动时，正常纹理、结构边界和缺陷区域仍可能混在一起。为刻画局部外观变化，本文在 CLIP patch 特征场上提取频域响应，将其作为局部结构变化的度量。低语义异常且结构变化稳定的 patch 更适合构成当前图像的正常参照；语义可疑且结构变化显著的 patch 从正常参照中剔除，并在后续重估中作为潜在异常区域被解释。由此，频域响应的作用落在证据选择和参照估计上，最终异常判读仍围绕当前图像的正常参照展开。

本文的贡献包括三个方面。第一，本文指出 CLIP-ZSAD 中的 reference gap：正常/异常文本原型提供跨图共享的语义参照，但缺少当前测试图像的正常外观基准。第二，本文提出一种训练无关的 image-conditioned normal reference estimation 方法，从单张测试图像的 patch 特征中估计正常外观参照，并用该参照重新解释局部异常响应。第三，本文将频域响应引入可靠 patch 证据选择，以刻画局部结构变化对参照估计的影响，并通过受控消融分析验证直接使用频域响应与估计图像条件化参照之间的差异。

## 可继续压缩的贡献句

本文指出 CLIP-ZSAD 中存在一个 reference gap：可学习的正常/异常文本原型能够形成稳定的语义轴，却不能给出当前测试图像的正常外观参照。为此，本文从测试图自身估计 image-conditioned normal reference，并用频域响应刻画 patch 层面的局部结构变化，使局部异常响应相对于当前图像的正常外观基准被解释。
