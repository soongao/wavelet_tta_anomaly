\begin{abstract}
基于 CLIP 的零样本异常定位通常面向目标类别无训练样本、无正常参考图像的协议，模型需要从单张测试图像输出图像级异常分数和像素级异常图。现有 CLIP-ZSAD 原型通过视觉 patch 与正常/异常文本原型匹配形成跨类别语义参照；但局部异常证据还取决于当前测试图像的正常外观。对于光滑物体而言，局部纹理变化可能对应缺陷；对于粗糙材质或重复结构而言，相似响应可能属于正常外观。本文将这一缺失的图像条件化基准概括为 \clipzsad{} 中的 reference gap。文本侧诊断进一步表明这一问题：当诊断提示中显式加入当前图像的材质、表面纹理或结构描述时，部分定位图会发生改变，说明外观上下文会影响局部响应的解释。基于这一观察，本文提出 \method{}，一种接入已有 \clipzsad{} 原型的图像条件化正常参照估计方法。该方法保持编码器和文本原型冻结，不进行测试时反向传播或参数更新，而是从当前测试图像的 patch 证据估计正常参照，利用小波局部结构响应刻画证据可靠性，并基于估计参照重新计算异常响应。主结果覆盖五个工业基准；MVTec AD 和 VisA 上的受控消融显示，直接把局部结构响应作为异常分数会降低定位指标，固定全局参照弱于图像条件化参照，而边界感知证据选择可在语义证据选择基础上进一步改善定位指标。

\noindent\textbf{关键词：} 零样本异常定位，CLIP，图像条件化正常参照，小波局部结构响应，patch 证据选择
\end{abstract}
