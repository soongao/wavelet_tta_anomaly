\section{分析}
\label{sec:analysis}

\subsection{Reference Gap 的证据}

表~\ref{tab:detail-prompt-diagnostic} 给出文本侧的诊断证据。在 MVTec 样例中，oracle detailed prompt 明确写入当前缺陷外观后，异常区域与背景区域的响应间隔平均增加 $0.207$；在 generic prompt 原本响应不足的样例中，detailed prompt 对标注异常区域的平均覆盖恢复为 $0.060$。这说明 patch response 不只由训练得到的通用 abnormal 语义决定，还会被当前样本的具体外观信息调节。

\input{tables/detail_prompt_diagnostic}

受控结果进一步支持 reference gap 的叙事。将 wavelet 响应直接混入异常图时，MVTec 的 Pixel AUPRO 降至 $80.4$，VisA 降至 $85.1$，低于最终图像条件化参照结果。Global 相对 Direct 有明显改善，但仍低于 \method{}：MVTec 的 Pixel AUPRO 差距为 $1.9$，VisA 的差距为 $2.5$。Sem 是强基线，说明主要增益来自当前图像参照估计本身；Struct 进一步改善了用于估计参照的 patch 证据选择。

\subsection{局部结构响应设计}

表~\ref{tab:wavelet-design-ablation} 隔离了频域响应的使用方式。HF 只使用高频幅值，不抑制结构边界。Bnd 使用式~\eqref{eq:structural-response} 降低由低频结构边界解释的响应。最终方法进一步加入保守正常参照估计。这个设计使频域响应的作用落在证据选择阶段。

\subsection{正常图稳定性}

正常侧参照采用保守更新。表~\ref{tab:normal-stability} 报告正常图中超过两个高响应阈值的面积。\method{} 在两个数据集上均没有增加该误报面积，这与正常参照校正的定位一致：方法调整的是当前图像的正常外观基准，而不是放大异常图响应。
