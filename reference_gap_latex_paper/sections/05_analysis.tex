\subsection{Reference Gap 的诊断证据}

表~\ref{tab:detail-prompt-diagnostic} 给出文本侧的诊断证据。在 MVTec 样例中，detailed prompt 写入当前缺陷外观后，异常区域与背景区域的响应间隔平均增加 $0.207$；在 generic prompt 原本响应不足的样例中，标注异常区域的平均覆盖恢复为 $0.060$。这一实验说明 patch response 同时受到通用 abnormal 语义和当前样本具体外观信息的调节；\method{} 在推理流程中通过图像侧 patch 证据建模这类外观上下文。

\input{tables/detail_prompt_diagnostic}

MVTec AD 和 VisA 上的受控结果进一步支持 reference gap 的解释。将 wavelet 响应直接混入异常图时，MVTec 的 Pixel AUPRO 为 $80.4$，VisA 为 $85.1$，低于基于参照估计的变体。Global 相对 Direct 有明显改善，但仍低于 \method{}：MVTec 的 Pixel AUPRO 差距为 $1.9$，VisA 的差距为 $2.5$，说明固定参照不足以刻画当前图像的正常外观。Sem 是强基线，表明主要改进来自当前图像参照估计；Struct 在 Sem 基础上继续提高 Pixel AUPRO，说明边界感知结构响应主要通过改善证据选择发挥作用。

\subsection{正常图稳定性}

正常侧参照采用保守更新。表~\ref{tab:normal-stability} 报告正常图中超过两个高响应阈值的面积。\method{} 在两个数据集上均保持该误报面积稳定。这一结果与方法设计一致：图像条件化参照用于调整正常外观基准，并约束异常响应的放大范围。
