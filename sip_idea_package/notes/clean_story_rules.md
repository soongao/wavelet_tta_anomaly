# Clean Story Rules

## 最外层故事

```text
静态图文相似度不足 -> 用结构扰动视图探测正常判别是否保持不变 -> 测试时形成结构共识 -> 无法被共识吸收的残差是异常
```

## 模块角色

- 小波：结构扰动探针，不是异常特征分支。
- TTA：结构共识形成机制，不是泛泛的推理增强。
- confidence/trimmed selection：防止异常被一致性目标吸收。
- residual score：异常定位的关键证据。

## 禁止叙事

- 不写成“小波 + TTA”。
- 不把异常写成单一频域现象。
- 不写成“普通 TTA 提升鲁棒性”。
- 不隐藏 TTA 代价。
- 不更新 CLIP backbone，除非明确作为消融。
