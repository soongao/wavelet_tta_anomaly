\section{Conclusion}
\label{sec:conclusion}

This draft addresses a reference gap in CLIP-based zero-shot anomaly
localization: fixed text prototypes provide generic normal/abnormal semantics,
but not the normal-appearance reference of the current test image. Local CLIP
responses and frequency-derived local signals are treated as candidate cues
whose evidence value depends on that image context. \method{} uses these cues
to select reliable patch evidence, constructs image-conditioned prototypes, and
recomputes patch anomaly scores in the frozen CLIP semantic space. The current
controlled results support the intended mechanism: direct local-cue fusion is a
negative control, GlobalRef remains below image-conditioned reference
estimation, semantic-only prototype adaptation is a strong baseline, and
boundary-aware reliability with conservative calibration gives the best
controlled row on MVTec AD and VisA.
