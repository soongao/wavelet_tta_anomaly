# NCMA 论文故事脊柱

## 一句话命题

CLIP-ZSAD 已经在很大程度上解决了异常语义如何跨类别迁移的问题，但仍默认同一组 normal/abnormal 语义锚能够定义每个目标实例的正常性边界；NCMA 将零样本异常定位重构为实例条件化正常性边界估计，用当前图像中的正常变异结构决定哪些局部证据可被接受为正常，哪些残差必须保留为异常。

## 核心问题重构

既有 CLIP-ZSAD 方法主要围绕状态语义展开：如何构造对象无关 abnormal concept，如何让 patch 与 normal/abnormal 文本状态对齐，如何通过提示或适配器增强状态判别。
这条路线提升的是语义迁移能力。

工业异常定位还需要另一类迁移能力：边界迁移。
同一 normal 语义在不同实例中对应不同的可接受外观范围；纹理方向、材质批次、局部几何和成像条件会改变当前图像中仍然正常的局部变化。
因此，异常定位不能只比较 patch 与固定 normal/abnormal 锚的距离，还需要估计当前实例的 normality boundary。

## 方法必要性

实例条件化正常性边界不是一个新的 normal 原型。
一个原型只能移动边界中心，不能刻画该中心附近哪些方向的变化仍可接受。
正常区域在局部邻域内呈现结构化变异：边缘连续、纹理延展、材质起伏和光照变化都具有方向性与尺度。
缺陷区域的关键证据则是无法由这些正常变异解释的残差。

NCMA 因此用正常变化流形表示实例边界。
局部 anchor 表示当前图像中的正常外观模式；切空间表示该模式附近的可容许变异方向；残差尺度规范化边界外偏离。
流形内投影用于估计当前实例的 normality boundary，流形外残差用于异常定位。

## 论文贡献表达

1. 将 CLIP-ZSAD 的核心瓶颈从“异常语义是否可迁移”推进到“正常性边界是否可在实例上成立”。
2. 提出实例条件化正常性边界估计，并用单图像正常变化流形实现边界表示。
3. 将局部证据分解为边界内变异和边界外残差，使 normal 语义更新与异常证据保留在同一机制中完成。
4. 用 MVTec AD 上的类别级结果和结构消融验证该边界建模带来的定位收益。

## 禁止写法

- 不把 NCMA 写成普通推理阶段参数适配或 prompt adaptation。
- 不把流形写成孤立模块或装饰性几何词。
- 不写把核心贡献交给实验结果决定的退让式句子。
- 不把结果表当作论文主线；结果只验证故事中的边界迁移命题。
