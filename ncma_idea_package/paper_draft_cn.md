# 正常变化流形适应：面向零样本异常检测的流形内校准与流形外定位

## 摘要

CLIP 零样本异常检测需要把预训练视觉语言模型从类别识别转向状态判断。现有方法已经能够构造 normal/abnormal 语义，但测试图像进入模型时仍带着自己的光照、视角、材质纹理和生产波动。这里的关键问题不是“要不要在测试时更新”，而是“哪些测试时变化有资格驱动更新”。在异常检测中，正常成像变化应被吸收，缺陷造成的局部偏离则必须保留下来。

本文提出正常变化流形适应（Normal-Change Manifold Adaptation, NCMA），将测试时适应重新定义为正常变化流形上的校准。NCMA 的核心主张是：正常样本并不形成一个静态原型，而是在 CLIP patch 表示空间中形成一组可迁移的正常变化轨道；测试时更新只能沿这些轨道发生，离开轨道的残差就是异常定位证据。为此，NCMA 从源域正常 patch 学习对象无关的正常变化流形图谱。测试时，目标图像及其增强视图形成 patch 级变化轨迹，每个轨迹先被投影到最近的正常变化流形邻域。投影后的流形内分量作为当前图像的伪正常目标，用于临时校准 prompt/adapter；投影无法解释的流形外残差从更新目标中剥离，并与 CLIP 的 normal/abnormal 语义分数共同生成异常图。这样，流形不是附加评分器，而是定义测试时适应的区域、方向和边界。

## 1. 引言

工业异常检测关注状态偏离。一个产品出现划痕、污染、裂纹或缺失部件时，它在类别语义上仍然是原来的对象；真正变化的是局部状态是否仍符合正常生产形态。CLIP-ZSAD 因此需要把 CLIP 的开放词汇能力转化为可迁移的正常/异常状态判断。

已有 CLIP-ZSAD 方法主要解决语义侧的问题：如何让 normal/abnormal 提示不依赖目标类别，如何利用图像上下文补充不可得的文本信息，如何让轻量参数获得异常概念。这些方法让模型在未见类别上具备静态异常判别能力，但推理阶段仍会遇到实例级变化。相同类别的正常样本会因为光照、视角、材质批次和纹理方向发生明显偏移；这些偏移如果不校准，会造成误报。

直接套用普通测试时适应并不能解决这个问题。普通 TTA 通常把当前样本中的不一致、低置信或跨增强波动视为需要压平的目标信号；在分类任务中，这通常是合理的。但异常检测里的局部缺陷本身就表现为难解释、不稳定或与上下文不一致。如果全图区域都参与更新，模型会把异常偏离也吸收到当前样本的“新正常”中，异常热图反而被抹平。

本文的出发点是：ZSAD 的测试时变化必须先被几何判定，再被用于适应。正常变化不是任意噪声，而是沿着正常样本在表示空间中的低维轨道移动；异常不是简单的大距离点，而是离开这些正常变化轨道的局部残差。基于这一观察，我们提出 NCMA，用正常变化流形来定义测试时更新的可行空间。模型只根据流形内变化校准当前图像，流形外残差不进入更新目标，而是直接成为定位证据。

本文贡献如下：

1. 将 CLIP-ZSAD 的测试时适应重构为正常变化流形上的实例校准，明确区分可适应的正常变化和不可适应的异常偏离。
2. 构建对象无关正常变化流形图谱，用源域正常 patch 学习可迁移的正常局部轨道，而不是目标类别原型。
3. 设计流形投影驱动的测试时更新：流形投影提供伪正常目标，流形外残差从优化中剥离并进入异常评分。
4. 给出与该主张对应的实验设计，重点比较普通 TTA、仅流形评分、仅流形筛选、投影目标移除和完整 NCMA。

## 2. 相关工作

### 2.1 CLIP 零样本异常检测

CLIP-ZSAD 利用视觉语言模型的开放词汇能力，在未见类别上进行异常分类和定位。该方向通常通过状态词、对象无关提示、视觉上下文或轻量适配器，把类别识别模型改造成正常/异常状态判别器。NCMA 不替代这些语义构造，而是在其上处理推理阶段的实例级正常变化，使静态 normal/abnormal 语义能够贴合当前测试图像。

### 2.2 测试时适应

测试时适应利用无标签测试样本进行临时更新。Tent 通过熵最小化调整归一化参数，MEMO 依赖增强视图的一致性，TPT 在 CLIP 中更新 prompt。它们共同假设测试时信号可以安全地推动模型适应。NCMA 改变这一假设：在 ZSAD 中，测试时信号必须先经过正常变化流形分解；只有流形内分量能参与更新，流形外分量保留为异常证据。

### 2.3 正常性几何建模

传统异常检测常用正常特征分布、记忆库或局部邻域来刻画正常性。几何方法进一步强调正常样本之间的结构关系。NCMA 借用这一思想，但目标不是单独计算一个正常距离分数，而是用正常变化流形定义测试时适应的可行轨道。流形在这里承担更新规则，而不仅是特征度量。

## 3. 方法

### 3.1 问题设置

给定冻结的 CLIP 图像编码器、文本编码器以及 normal/abnormal 文本提示，目标是在未见目标类别上输出图像级异常分数和像素级异常图。训练阶段允许使用源域正常样本学习对象无关正常变化流形；测试阶段只访问当前无标签目标图像及其增强视图。NCMA 只临时更新小参数组，例如 prompt residual、轻量 adapter 或 normalization affine，更新后的参数仅用于当前测试图像。

### 3.2 对象无关正常变化流形

NCMA 从源域正常图像提取 CLIP patch 表示，并把这些表示组织成正常变化流形图谱。图谱由多个局部邻域组成，每个邻域包含一个正常中心、一组允许移动方向和对应尺度。这些局部邻域描述正常区域在光照、姿态、纹理方向、边缘连续性和制造波动下的可接受变化。

设源域正常 patch 表示为 \(z\)。对于第 \(k\) 个正常邻域，NCMA 维护中心 \(a_k\)、局部方向基 \(U_k\) 和尺度 \(\sigma_k\)。测试 patch \(z_i\) 被分配到最能解释它的正常邻域，并得到流形投影：

\[
\hat z_i = a_k + U_k U_k^\top (z_i - a_k).
\]

\(\hat z_i\) 是该 patch 在正常变化流形上的对应点，残差

\[
r_i = \|z_i - \hat z_i\| / \sigma_k
\]

表示正常变化流形无法解释的偏离程度。NCMA 使用 \(c_i=\exp(-r_i)\) 作为流形兼容权重。高兼容 patch 被视为当前图像中的正常变化证据；高残差 patch 被视为异常候选。

### 3.3 测试时变化轨迹分解

给定测试图像，NCMA 生成多个增强视图，并对每个视图提取 patch 表示。对于同一空间位置的 patch，原图和增强视图形成一条测试时变化轨迹：

\[
\tau_i = \{z_i^{(0)}, z_i^{(1)}, \ldots, z_i^{(V)}\}.
\]

NCMA 不直接用这条原始轨迹更新模型，而是先把轨迹上的每个点投影到正常变化流形，得到流形内轨迹 \(\hat\tau_i\) 和流形外残差序列 \(r_i^{(v)}\)。流形内轨迹描述当前图像中正常区域如何随增强、成像和局部状态变化而移动；流形外残差描述这些变化中无法被正常轨道解释的部分。

这一分解让普通 TTA 和 NCMA 的差别变得明确。普通 TTA 优化原始轨迹的一致性，默认整条轨迹都可信。NCMA 优化流形投影后的正常轨迹，并把离开流形的残差从更新中拿走。换言之，NCMA 不是在 TTA 外面加一个筛选器，而是把 TTA 的目标从“原始测试样本”替换为“正常流形上的测试样本投影”。

### 3.4 流形投影驱动的测试时更新

NCMA 使用流形兼容权重选择更新信号。对于兼容权重高的 patch，投影点 \(\hat z_i^{(v)}\) 作为当前图像的伪正常目标，促使 prompt/adapter 吸收当前实例中的正常成像和纹理变化。对于残差高的 patch，NCMA 不把它们纳入更新损失，并阻断残差对可更新参数的梯度，使异常偏离不会被适应过程抹平。

更新目标包含两项。第一项是流形内一致性：同一正常区域在不同增强视图下的预测应围绕其流形投影保持稳定。第二项是正常语义校准：高兼容 patch 在更新后应更接近 normal 语义，而不是被异常提示牵引。整体更新只执行少量步，并且只作用于当前测试图像的小参数组。

经过这一过程，模型获得的是当前图像的正常变化校准，而不是对整张图像的无差别拟合。流形内变化被吸收，流形外残差仍保持可见。

### 3.5 异常评分

最终 anomaly map 融合两类证据。第一类是 CLIP 语义异常分数，即 patch 与 abnormal prompt 相对 normal prompt 的相似度差异。第二类是流形外残差分数，即 patch 离开正常变化流形的程度。对于第 \(i\) 个 patch，NCMA 使用

\[
A_i = \lambda A_i^{sem} + (1-\lambda) A_i^{man}
\]

得到最终异常分数，其中 \(A_i^{sem}\) 来自更新后的 normal/abnormal 语义比较，\(A_i^{man}\) 来自增强视图上的流形外残差聚合。像素级异常图由 patch 分数上采样得到，图像级分数由 top-k patch 分数聚合得到。

## 4. 实验设计

### 4.1 主实验

主实验在 MVTec AD 和 VisA 上报告图像级与像素级指标：

- 图像级：I-AUROC、I-AP、I-F1-max；
- 像素级：P-AUROC、P-AP、P-F1-max、P-AUPRO。

主比较包含 CLIP baseline、WinCLIP、AnomalyCLIP、VCP-CLIP、AA-CLIP、测试时增强、普通 TTA/TPT 和 NCMA。NCMA 的核心效果体现在异常定位，因此 P-AP、P-AUPRO 和 P-F1-max 是主要观察指标。

### 4.2 消融实验

核心消融围绕“流形定义适应边界”展开：

| 变体 | 验证点 |
|---|---|
| 静态推理 | 固定 CLIP-ZSAD 基线 |
| 测试时增强 | 多视图集成本身的作用 |
| 普通 TTA | 原始测试轨迹直接更新是否抹平异常 |
| 仅流形外残差评分 | 流形残差作为定位证据的独立作用 |
| NCMA 去掉投影目标 | 只筛选 patch、不把更新目标放到流形上是否不足 |
| NCMA 去掉残差剥离 | 异常候选进入更新后是否损害定位 |
| NCMA 去掉流形外评分 | 只做流形内校准是否不足 |
| 完整 NCMA | 流形投影校准与流形外定位的联合效果 |

### 4.3 机制可视化

机制图展示四类结果。第一，正常变化流形的局部邻域和测试 patch 投影。第二，流形内兼容权重图，显示哪些区域驱动测试时更新。第三，流形外残差热图，显示哪些区域被保留为异常证据。第四，普通 TTA 与 NCMA 的异常图对比，展示原始轨迹更新和流形投影更新的定位差异。

## 5. 讨论

NCMA 把测试时适应从通用鲁棒性工具转化为正常流形上的校准机制。它给每个测试时变化一个明确去向：能够被正常变化流形解释的部分推动当前图像校准，不能被解释的残差进入异常定位。这样，模型既能适应实例级正常波动，又不会把局部缺陷学习成当前样本的正常状态。

## 6. 结论

本文提出正常变化流形适应 NCMA，用于 CLIP 零样本异常检测的测试时校准。NCMA 的中心主张是：测试时适应必须沿正常变化流形进行，离开该流形的局部残差必须保留为异常证据。通过对象无关正常变化流形、测试时轨迹投影、流形内更新和流形外评分，NCMA 将无标签测试时更新转化为直接服务异常定位的机制。
