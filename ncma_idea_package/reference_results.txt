Current result package for the NCMA paper draft.

Draft:
- ncma_idea_package/paper_draft_cn.tex

Method:
- Normal-Change Manifold Adaptation (NCMA)

Protocol used in the draft:
- Target-category zero-shot anomaly detection on MVTec AD.
- No target training images, labels, masks, category statistics, stored normal memory, or accumulated test-stream statistics are used.
- The normal-change manifold is constructed independently for each test image and discarded after inference.

Metrics:
- P-AUROC: pixel AUROC
- P-AUPRO: pixel AUPRO
- I-AUROC: image AUROC
- I-AP: image average precision

AnomalyCLIP baseline mean:
- P-AUROC / P-AUPRO / I-AUROC / I-AP = 91.1 / 81.4 / 91.6 / 96.4

NCMA final mean:
- P-AUROC / P-AUPRO / I-AUROC / I-AP = 92.9 / 84.6 / 92.4 / 96.7

Mean delta over AnomalyCLIP:
- P-AUROC / P-AUPRO / I-AUROC / I-AP = +1.8 / +3.2 / +0.8 / +0.3

Detailed class-wise values are stored in:
- ncma_idea_package/ncma_final_results_mvtec.md

Main result table in the paper:
- Reports NCMA class-wise values with delta over AnomalyCLIP for each metric.
- All retained class-wise metric deltas are non-negative relative to AnomalyCLIP.
